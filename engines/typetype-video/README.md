# TypeType Video Engine

A degoog search engine plugin that proxies video searches through a self-hosted [TypeType](https://typetype-video.github.io/Docs-TypeType/) instance.

## Settings

| Setting | Type | Default | Description |
|---------|------|---------|-------------|
| Instance URL | url (required) | — | Your self-hosted TypeType server URL |
| Result link type | select | watch | `/watch` page or `/embed` player |
| YouTube | toggle | on | Search YouTube |
| Bilibili | toggle | off | Search Bilibili |
| Niconico | toggle | off | Search Niconico |
