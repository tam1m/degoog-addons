# degoog-addons

[TypeType](https://github.com/Priveetee/TypeType) stuff for [degoog](https://github.com/degoog-org/degoog).

## engine

[TypeType](engines/typetype-video/) searches YouTube, Bilibili, and Niconico through your own TypeType instance. shows up in web and videos tabs. per-service toggles, watch/embed links, `!tt` bang.

## slot

[Inline Player](plugins/typetype-player-slot/) drops a collapsible video card above results when you're probably looking for a specific video. click to play.

## install

add `https://github.com/tam1m/degoog-addons` in degoog settings > store.
